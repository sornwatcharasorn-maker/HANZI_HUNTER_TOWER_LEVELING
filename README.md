# ไฟล์เกมมีสองใบ — แก้ที่ต้นฉบับ แจกที่ไฟล์ย่อ

| ไฟล์ | คืออะไร |
|---|---|
| `src/hanzi_hunter_tower_v3_1_intro.src.html` | **ต้นฉบับ** อ่านง่าย คอมเมนต์ครบ — **แก้ที่นี่** |
| `hanzi_hunter_tower_v3_1_intro.html` | **ไฟล์แจกนักเรียน** ย่อแล้ว — **ห้ามแก้มือ** |

```

node build_minify.js           # ต้นฉบับ → ไฟล์แจก

```

ไฟล์แจกยังเป็น HTML ใบเดียวที่ไม่อ้างอะไรจากข้างนอกเลย เปิดจาก `file://` ออฟไลน์ได้เหมือนเดิม

(ชั้น v8.7 · Skill Sprite Animation Engine กินไป ~6.2KB ที่ตรรกะกับ CSS ล้วน โดยคืนที่มาก่อน

— แถบซ้ายกล่องล็อกอินใช้ความกว้างจริงราว 370 CSS px 512px จึงยังเกินอยู่ 1.38 เท่า

ยังไม่มีไฟล์ในrepoเลย · เครื่องยนต์ทำงานครบทุกข้อแล้ว รอแค่เสียบ data URI ลงทะเบียน

# กระดานผู้นำห้องเรียน — ต้องเปิดสิทธิ์โหนด `/rooms` เพิ่มหนึ่งก้อน

กระดานผู้นำ (ปุ่ม 🏆 LEADERBOARD ในเกม) ซิงค์ข้ามเครื่องผ่าน Firebase RTDB
โหนด `/rooms/{ห้องเรียน}/leaderboard/{รหัสฮันเตอร์}` โดยใช้ URL ชุดเดียวกับที่
ระบบซิงค์ห้องควบคุมใช้อยู่แล้ว **ไม่ต้องตั้งค่าอะไรเพิ่มบนเครื่องนักเรียน**

แต่ต้องเติม Rules อีกก้อนในคอนโซล Firebase ครั้งเดียว (ของเดิมเปิดไว้แค่ `students`)

```json
{ "rules": { "students": { ".read": true, ".write": true },
             "rooms":    { ".read": true, ".write": true } } }
```

**ยังไม่เติมก็ยังเล่นได้** — กระดานจะตกไปอ่านโหนด `/students` ที่ทุกเครื่องส่งอยู่แล้ว
เพื่อนร่วมห้องจึงขึ้นกระดานตั้งแต่วันแรก ส่วนคำขอเขียนที่ถูกปฏิเสธจะถูกจดลง Error Log
ในเกมเงียบ ๆ ไม่ทำให้เกมพัง · ปิดเน็ต/ไม่ได้ตั้งค่าคลาวด์ = กระดานโชว์เฉพาะข้อมูลในเครื่อง
เหมือนก่อนมีระบบนี้ทุกประการ

**โหนดนี้เป็นจอแสดงผลล้วน** — มีแต่ชื่อ · เลเวล · ชั้น · รอบ · ความแม่นยำ · ฉายา · สตรีค
**ไม่มีรหัสผ่านและไม่มีแม้แต่แฮชขึ้นไป** ระดับความปลอดภัยเท่ากับโหนด `/students` เดิมเป๊ะ
คือกันเด็กกดเล่น ไม่ได้กันคนตั้งใจ

# ภาพประกอบในเกม — ไฟล์ต้นฉบับและวิธีฝัง

กฎไฟล์เดียวจบห้ามอ้าง path ภายนอก (ไฟล์ถูกส่งต่อทาง LINE / เปิดออฟไลน์)
ไฟล์ `.jpg` ใน repo เป็น **ต้นฉบับเท่านั้น** ตัวเกมไม่ได้อ่านตอนรัน
ต้องย่อ → WebP → base64 → ฝังเป็นค่าคงที่ในไฟล์เกมก่อนถึงจะขึ้นจอ

## ต้นฉบับที่อยู่ใน repo ตอนนี้ — ไอคอนสกิล 4 + ประตูวาป

| ไฟล์ | ใช้กับ | ฝังที่ |
|---|---|---|
| `เนตรพินอิน.jpg` | 👁️ จิตอักขระ: เนตรพินอิน | `SKILLS[eye].img` |
| `ดาบโลหิต.jpg` | ⚔️ ทลายอักษร: ดาบโลหิต | `SKILLS[blade].img` |
| `นาฬิกาเยือกแข็ง.jpg` | ❄️ มิติเวลา: นาฬิกาเยือกแข็ง | `SKILLS[frost].img` |
| `ฟื้นคืนชีพ.jpg` | 🛡️ เกราะอักขระ: ฟื้นคืนชีพ | `SKILLS[ward].img` |
| `วาป.jpg` | ประตูวาปมิติ (หลังบอส) | `SN_WARP_ART` |

```
python3 embed_icon_art.py            # ฝังทุกรูปที่หาไฟล์เจอ
python3 embed_icon_art.py eye warp   # ฝังเฉพาะบางรูป
```

**ชื่อไฟล์ = ชื่อสกิลภาษาไทยเป๊ะ ๆ** (ตัดคำนำหน้าข้างหน้า `:` ออก) สคริปต์อ่านชื่อจาก
ฟิลด์ `name` ของ `SKILLS` ในตัวเกมเอง จึงไม่มีสารบัญสองที่ให้ต้องซิงก์
ไอคอนสกิลย่อเหลือ 96px (แสดงจริง 26×26 CSS px) · ประตูวาปกว้างไม่เกิน 720px
รูปไหนหาไฟล์ไม่เจอจะถูกข้าม ของที่ฝังไว้แล้วไม่ถูกแตะ

## ต้นฉบับที่ถูกลบไปแล้ว — การ์ด 17 ใบ และ `TOWER.png`

Asset Replacement Patch (ส.ค. 2026) ลบไฟล์ต้นฉบับชุดเก่าออกจาก repo เพื่อลดขนาดโปรเจกต์
จาก ~11.7MB เหลือ ~1.9MB **ภาพที่ฝังไว้ในไฟล์เกมยังอยู่ครบทุกรูป เกมไม่กระทบเลย**
(การ์ด 17 ใบ ~557KB · หอคอยในเรดาร์ ~105KB · มาสคอต ~110KB)

จะฝังภาพชุดพวกนี้ใหม่ได้ก็ต่อเมื่ออัปโหลดไฟล์ต้นฉบับกลับเข้ามาก่อน —
ชื่อไฟล์การ์ดดูได้จากฟิลด์ `image` ของแต่ละใบใน `CD_CARDS` (สารบัญยังอยู่ครบ)
หรือดึงไฟล์เดิมจากประวัติ git ก็ได้ (`git log --diff-filter=D --name-only`)

```
python3 embed_card_art.py              # ฝังการ์ดทุกใบที่หาไฟล์เจอ
python3 embed_card_art.py ward edge    # ฝังเฉพาะบางใบ
python3 embed_card_art.py --clear      # ถอดภาพการ์ดทุกใบกลับไปใช้อีโมจิ
python3 embed_tower_art.py TOWER.png   # ฝังภาพหอคอยของเรดาร์ v4.5
python3 embed_monster_art.py           # ฝังอสูรประจำชั้น 18 ตัว (v6.2)
python3 embed_hero_art.py              # ฝังเฟรมฮีโร่ (v6.5)
python3 embed_abyss_art.py             # ฝังทัพเงา 25 ตัว (v6.6)
```

## ข้อแนะนำเรื่องภาพ

- **การ์ด: สัดส่วนแนวตั้ง 3:4** (ชุดที่ใช้อยู่คือ 350×~470) แสดงแบบ `object-fit:contain`
  **ไม่ crop** จึงเห็นทั้งใบครบกรอบ — ภาพที่มีกรอบลายของตัวเองใช้ได้เลย
- **ไอคอนสกิล: จัตุรัสหรือใกล้เคียง** CSS บังคับ `width/height` เท่ากัน คลาดได้ราว 3% ไม่มีใครดูออก
- ความละเอียดต้นฉบับเท่าไรก็ได้ สคริปต์ย่อให้เอง (ไม่ขยายเกินต้นฉบับ)
- ไฟล์เกมตอนนี้ ~1.61MB **เพดานอยู่ที่ 2MB** ทุกสคริปต์หยุดให้เองถ้าจะทะลุ
