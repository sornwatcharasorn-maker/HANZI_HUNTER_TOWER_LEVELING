## ตัวเกมไม่ได้อ่านไฟล์ในโฟลเดอร์นี้ตอนรัน

กฎไฟล์เดียวจบห้ามอ้าง path ภายนอก (ไฟล์ถูกส่งต่อทาง LINE / เปิดออฟไลน์)
ไฟล์พวกนี้เป็น **ต้นฉบับเท่านั้น** เหมือน `.jpg` ของสกิล/ประตูวาปที่วางไว้ราก repo
ต้องย่อ → WebP → base64 → ฝังลงฟิลด์ `img` ของการ์ดก่อนถึงจะขึ้นจอ:

```
python3 embed_card_art.py              # ฝังทุกใบที่หาไฟล์เจอ
python3 embed_card_art.py ward edge    # ฝังเฉพาะบางใบ
python3 embed_card_art.py --clear      # ถอดภาพทุกใบกลับไปใช้อีโมจิ
```

ใบไหนยังไม่มีไฟล์จะถูกข้าม การ์ดใบนั้นใช้อีโมจิเหมือนเดิม **ไม่มีรูปแตก**
จึงทยอยเติมทีละใบได้ ไม่ต้องรอให้ครบ 17 ใบ

## ข้อแนะนำเรื่องภาพ

- **สัดส่วนแนวตั้ง 3:4** (ชุดที่ใช้อยู่คือ 350×~470) ภาพถูกแสดงแบบ `object-fit:contain`
  **ไม่ crop** จึงเห็นทั้งใบครบกรอบ — ภาพที่มีกรอบลายของตัวเองใช้ได้เลย
- ความละเอียดต้นฉบับเท่าไรก็ได้ สคริปต์ย่อเหลือกว้าง 300px ให้เอง (ไม่ขยายเกินต้นฉบับ)
- 17 ใบทำให้ไฟล์เกมโตราว **+557KB** (จาก ~1.15MB เป็น ~1.67MB) เพดานอยู่ที่ 2MB
